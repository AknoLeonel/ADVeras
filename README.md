# AD Veras Advocacia

Site de escritório de advocacia especializado nas áreas tributária, trabalhista e previdenciária.

[![Ver site no ar](https://img.shields.io/badge/Ver%20site%20no%20ar-00F5FF?style=for-the-badge&labelColor=0D1117)](https://ad-veras.vercel.app) [![Portfólio](https://img.shields.io/badge/Portfólio-FF00E4?style=for-the-badge&labelColor=0D1117)](https://aknoleonel.github.io)

## Sobre o projeto

Site institucional com tom sóbrio e premium para um escritório de advocacia. Apresenta as áreas de atuação em detalhe, como planejamento tributário, holding patrimonial e compliance trabalhista, e leva à consultoria.

## Destaques

- Áreas de atuação organizadas em tributário, trabalhista e previdenciário
- Lista detalhada de serviços em cada área
- Chamada para consultoria especializada
- Animações discretas com Framer Motion

## Tecnologias

React · Vite · Framer Motion · Lucide Icons

## Rodando localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.
